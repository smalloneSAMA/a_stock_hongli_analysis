# A股红利研究项目

红利指数与ETF的观察池、成分股、历史行情数据与研究文档。

## 目录结构

```
a_stock_hongli_analysis/
├── 红利介绍.md              # 精选指数(10+1)与ETF(11)的研究文档（策略、规模、业绩）
├── 红利指数与ETF成分股.md   # 全部指数/ETF的成分股明细（含权重、数据来源）
├── 困难总结.md              # 项目过程困难与经验记录
├── update.py                # ★ 数据更新入口（交互式菜单）
├── scripts/                 # 全部脚本
│   ├── _fetch_history.py    # 历史行情拉取（指数K线/ETF K线+净值，支持增量）
│   ├── _fetch_stock_data.py # 推荐20只股票历史日线（不复权，2004-01-01起）
│   ├── _gen_components.py   # 指数成分股下载 + 重新生成成分股md
│   ├── _fetch_index_data.py # （原研究）候选指数行情/估值
│   ├── _fetch_etf_data.py   # （原研究）候选ETF规模/业绩
│   └── _find_index_code.py  # （原研究）指数代码查询
├── cache/                   # 历史行情缓存（JSON，指数11+ETF11+股票20）
├── excel/                   # 历史行情Excel（指数/ETF/股票历史.xlsx）
└── docs/                    # 参考资料（基金概况、招募说明书）
```

## 数据更新

```bash
python update.py
```

交互菜单：
| 选项 | 内容 | 说明 |
| :-- | :-- | :-- |
| 1 | 指数历史行情 | 增量更新（有缓存只拉新数据），运行前确认 |
| 2 | ETF历史行情 | 增量更新（场内K线+净值） |
| 3 | 指数成分股 | 重下载中证官网样本文件并重生成成分股md，运行前确认 |
| 4 | 成分股汇总表 | 解析成分股md→行业/行情/股息率→缓存→汇总Excel |
| 5 | 股票历史行情 | 推荐20只股票日线增量（不复权，2004-01-01起，首次全量约2-3分钟） |
| 6 | 全部更新 | 依次执行上述全部 |

- 增量更新：从缓存最后日期起拉取，无缓存则全量；更新后自动导出Excel
- 股票历史：腾讯不复权日K（真实价格），2004-01-01 起；成交额按量×100×均价估算（腾讯无成交额字段）；增量=拉最近800条+字段级合并
- 成分股更新：官网文件下载失败时自动用旧数据回退；全部失败则不重写文档
- 手动全量重拉：`python scripts/_fetch_history.py --refresh` / `python scripts/_fetch_stock_data.py --refresh`

## 缓存保护

- 全部缓存文件已提交至 git，误删可用 `git checkout -- cache/` 恢复
- 缓存被删后主流程可自愈：选项1/2 自动全量重拉历史行情；选项4 基于成分股md重建汇总缓存（行业/股息率会全量补齐，耗时约10分钟）
- 写缓存均为原子写（先写 .tmp 再替换），中断不会损坏缓存；JSON 损坏时选项4 会检测并自动重建
- 安全阀：md 解析结果与旧缓存差异过大（疑似 md 损坏）时跳过删除同步，只新增不清空，需人工核对

## 数据源

| 数据 | 来源 |
| :-- | :-- |
| 指数成分/权重 | 中证指数官网官方样本文件（csindex.com.cn）；932368/000151为东财成分表 |
| 指数历史行情 | 腾讯K线（5只，无成交额）+ 中证官网index-perf（5只，含成交额）+ 国证官网（980092，含成交额） |
| ETF历史行情 | 腾讯场内K线 + 新浪单位/累计净值 |
| 股票历史行情 | 腾讯日K（不复权，2004-01-01起，成交额估算）+ 东财分红历史（股息率逐日计算）+ 东财季度财报（PE-TTM/PE动/PB/ROE/ROA逐日计算） |
| 名称补齐 | 腾讯行情 |
