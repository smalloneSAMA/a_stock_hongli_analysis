红利指数与ETF的观察池、成分股、历史行情数据与研究文档。

## 前端展示页（web/）

4 个 Excel 表格的浏览器展示终端：指数历史（11只）/ ETF历史（11只）/ 股票历史（20只）/ 成分股汇总（289只）+ 回测报告页，深色金融科技风，红涨绿跌。

```bash
# 1. 生成前端数据包（指数/ETF/股票 K线直接读 cache/，股票逐日指标与 summary 由此脚本预计算，口径与 Excel 完全一致）
python scripts/_gen_web_data.py

# 2. 启动本地服务（项目根目录；serve.py 强制 no-cache，避免浏览器缓存旧 JS 导致图表不更新）
python serve.py

# 3. 浏览器打开
#    http://localhost:8000/web/index.html
#    （若此前打开过页面且图表空白，请按 Ctrl+Shift+R 强制刷新一次）
```

- 纯静态零依赖：HTML + 原生 JS（ES Modules）+ 本地 ECharts（web/vendor/）+ 本地 Fira 字体，离线可用
- 数据更新后重跑 `_gen_web_data.py` 即可（只读缓存，不触发任何网络请求；约 5 秒）；或 `python update.py` 选 7 一键（含区间分析重建）
- 股票逐日指标（股息率/PE-TTM/PE动/PB/PEG/ROE/ROA）复用 `_fetch_stock_data.py` 的 `calc_*` 函数，与 `excel/股票历史.xlsx` 同口径；主图可叠加 6 条指标曲线
- ETF 视图支持单位/累计净值叠加开关；成分股汇总支持搜索/行业筛选/推荐20只/任意列排序 + 行业分布环形图（点击扇区筛选）+ 股息率 TOP15

### 买卖区间分析（S1-S8）

- **数据**（`_gen_analysis.py`，S1-S5）：TTM 股息率反推历史序列（`cache/analysis_dy.json`）→ 5年滚动分位 → 四/六因子打分（指数：股息率/价格/趋势/情绪；股票：+PE/PB/PEG）→ 三档权重（稳健/均衡/进取）→ 买入/卖出点位锚（股息率90/10分位对应价格）→ `web/data/analysis.json`（只存因子分位，前端本地算分）；**980092/159201 的股息率由 ETF 季报持仓加权估算**（`_fetch_etf_holdings.py`）
- **回测**（`_backtest_analysis.py`，S2）：dy 上穿90分位=买/下穿10分位=卖，信号后 1/3/6/12 个月收益 vs 每日买入基准；p85/90/95 敏感性（分组粒度）；默认**全量约 360 标的**（11指数+11ETF+335股票，含其他成份股/自选股），按 指数/ETF/推荐20/其他成份股/自选股 五分组统计 → `docs/回测报告.md` + `web/data/backtest.json`；结论：指数层面显著有效（12M 超额 +24%），个股弱正（+0.6%）
- **前端**（S6-S8）：指数/ETF/股票详情页「区间分析」tab（分数仪表盘+因子明细+三档切换）；K线主图叠加买入/卖出锚虚线；股息率副图（近5年曲线+90/10分位线）；顶部「回测报告」页（三档切换+汇总卡+五分组卡+明细表，明细含分组列可筛选）
- **测试**（`_test_analysis.py`）：58 项断言（T1-T9 数据/结构/数值快照/边界/回测产物），`python scripts/_test_analysis.py` 一键回归；前端 19 项浏览器矩阵（CloakBrowser）

- 增量更新：从缓存最后日期起拉取，无缓存则全量；更新后自动导出Excel
- 股票历史：腾讯不复权日K（真实价格），2004-01-01 起；成交额按量×100×均价估算（腾讯无成交额字段）；增量=拉最近800条+字段级合并
- 成分股更新：官网文件下载失败时自动用旧数据回退；全部失败则不重写文档
- 手动全量重拉：`python scripts/_fetch_history.py --refresh` / `python scripts/_fetch_stock_data.py --refresh`

## 缓存保护

- 全部缓存文件已提交至 git，误删可用 `git checkout -- cache/` 恢复
- 缓存被删后主流程可自愈：选项1/2 自动全量重拉历史行情；选项4 基于成分股md重建汇总缓存（行业/股息率会全量补齐，耗时约10分钟）
- 写缓存均为原子写（先写 .tmp 再替换），中断不会损坏缓存；JSON 损坏时选项4 会检测并自动重建
- 安全阀：md 解析结果与旧缓存差异过大（疑似 md 损坏）时跳过删除同步，只新增不清空，需人工核对
