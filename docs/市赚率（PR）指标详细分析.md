
# 市赚率（PR）指标详细分析

## 一、市赚率是什么？

市赚率（Price-to-Earnings-to-Return-on-Equity Ratio，简称 PR）的核心公式为：

\[
PR = \frac{PE}{ROE} \div 100
\]

其中：

- **PE**：市盈率
- **ROE**：净资产收益率
- 除以 100 是为了处理 ROE 的百分比单位，使结果更直观。

若 ROE 用小数表示（如 15% 写成 0.15），则公式等价于：

\[
PR = \frac{PE}{ROE} \div 100
\]

例如：PE = 15，ROE = 15%，则：

\[
PR = \frac{15}{0.15} \div 100 = 1
\]

即 **1PR**。

市赚率的直观含义是：**你为每一单位净资产盈利能力支付了多少价格**。它同时考虑了估值（PE）和盈利质量（ROE），避免单纯低 PE 陷阱和高 ROE 泡沫。

---

## 二、核心公式与数学推导

### 1. 基本公式

\[
PR = \frac{PE}{ROE} \div 100
\]

### 2. 第二公式：用 PB 和 ROE 表示

由 \( PE = \frac{PB}{ROE} \) 得：

\[
PR = \frac{PB}{ROE^2} \div 100
\]

适用于周期股和困境反转型公司，因为盈利波动大时 PE 易失真，但 PB 相对稳定，可用长期平均 ROE 平滑。

### 3. 第三公式：用 PE 和 PB 表示

由 \( ROE = \frac{PB}{PE} \) 得：

\[
PR = \frac{PE^2}{PB} \div 100
\]

适用于指数基金，因为多数指数只公布 PE 和 PB，不直接公布 ROE。

### 4. 衍生公式：ROE 过高时用 ROA 替代

当 ROE 超过 50% 时（尤其高杠杆企业），ROE 容易虚高失真，改用 ROA：

\[
衍生PR = \frac{PE}{ROA} \div 150
\]

其中 150 是经验调整系数。

---

## 三、估值阈值与巴菲特案例

### 1. 估值标准

- **PR = 1**：合理估值
- **PR < 1**：低估
- **PR > 1**：高估

### 2. 巴菲特买入可口可乐

- 1988 年买入市赚率：0.474PR
- 1989 年买入市赚率：0.326PR
- 两年平均：0.4PR

因此“**40 美分买入 1 美元**”成为巴菲特口头禅。通常巴菲特在 **0.4PR～0.6PR** 之间买入。

### 3. 巴菲特估值中国石油 H 股

- 1999—2002 年中国石油平均 ROE ≈ 15.88%
- 巴菲特买入均价对应 PB ≈ 0.96 倍
- 市赚率 = 0.96 / (0.1588²) / 100 ≈ **0.38PR**
- 当时总市值 370 亿美元，巴菲特称内在价值约 1000 亿美元

反推验证：

\[
\frac{0.38}{1} = \frac{370}{X} \Rightarrow X \approx 974 \text{亿美元} \approx 1000 \text{亿美元}
\]

说明市赚率与巴菲特估值思路高度契合。

## 四、修正系数 N：处理“赚真钱”与“赚假钱”

### 1. 修正逻辑

以 50% 股利支付率为标杆：

\[
N = \frac{50\%}{股利支付率}
\]

- 股利支付率 ≥ 50%：N = 1.0
- 股利支付率 ≤ 25%：N = 2.0
- 中间值线性插值（例如 40% → N = 1.25）

修正后市赚率：

\[
修正PR = N \times \frac{PE}{ROE} \div 100
\]

### 2. 适用条件

仅适用于 **ROE 稳定的价值股**，不适用于：

- 周期股（景气年份分红波动大）
- 科技股（常用回购代替分红）
- 成长股（利润需留存）

### 3. 案例

- **贵州茅台**：股利支付率高，接近“赚真钱”，N ≈ 1，合理估值可接近 1PR
- **美的集团**：分红中等，N ≈ 1.25，合理估值约 0.8PR
- **招商银行**：股利支付率偏低，N 较高，合理估值约 0.6PR

这解释了为何不同行业估值水平长期存在差异。

---

## 五、周期股应用：第二公式与“耕种模式”

### 1. 为什么周期股不能直接用 PE？

周期股景气顶点盈利暴增 → PE 极低但可能是顶部；萧条期盈利下滑甚至亏损 → PE 极高或为负但可能接近底部。因此改用：

\[
PR = \frac{PB}{ROE^2} \div 100
\]

其中 ROE 使用多年平均值或景气周期中最低一年的 ROE，以保守估值。

### 2. 合理 PB 与 ROE 的平方关系

当 PR = 1 时：

\[
PB = ROE^2 \times 100
\]

- ROE = 10% → 合理 PB = 1 倍
- ROE = 15% → 合理 PB = 2.25 倍
- ROE = 20% → 合理 PB = 4 倍

高 ROE 企业的合理估值呈平方级上升。

### 3. 买卖信号

- 行业龙头景气年份平均 ROE 约 15%，合理 PB 约 2.25 倍；**跌破 1 PB 即不到半价**
- 主流企业平均 ROE 约 10%，合理 PB 约 1 倍；**跌破 0.5 PB 即不到半价**

策略：**萧条年份明显破净时关注，景气年份估值修复后卖出**（耕种模式）。

### 4. 辅助信号

- 期货价格右侧信号
- 反内卷政策信号（如煤炭供给侧改革、猪肉行业反内卷、多晶硅行业反内卷）

### 5. 局限性

部分龙头周期股萧条期也拒绝破净（如紫金矿业），此时市赚率难以给出明显买点。

---

## 六、指数基金应用：第三公式

指数基金通常不直接披露 ROE，使用：

\[
PR = \frac{PE^2}{PB} \div 100
\]

### 案例：中证红利质量指数与 ETF 159209

- 编制方案：高股息率（低 PE）+ 低 ROE 标准差（高且稳定的 ROE），与市赚率逻辑相似。
- 上市初期 PR ≈ 0.75PR，后跌至 0.7PR 以下，随后反弹至 1PR。
- 若 7 折买入、1PR 卖出，10 个月收益约 43%；8 折买入则约 25%。

注意：指数基金半年调仓一次，牛市可能不够，需结合市赚率手动减仓。

---

## 七、市赚率与 DCF 的关系

市赚率可看作 **DCF 的简化版**。

- 当 ROE 在 10%～33% 之间时，市赚率与 DCF 计算结果接近。
- 折现率影响：
  - 低利率环境：合理估值可上移至 1.1～1.4PR
  - 高利率环境：合理估值下移至 0.7～0.9PR

因此 1PR 只是基准，实际需结合利率环境调整。

---

## 八、市赚率的“隐形参数”

虽然核心参数只有 PE 和 ROE，但实际运用还需关注：

1. **增长率**：长期增长率最好达到 ROE 的一半以上，才能实现接近 ROE 的复利。
2. **负债率**：不宜超过行业平均；银行股另需关注拨备覆盖率（低于 300% 基本不考虑）。
3. **折现率**：利率越高，对高估值容忍度越低。
4. **股息率**：当无风险利率高达 5% 时，股息率低于 5% 的 H 股吸引力下降。

---

## 九、市赚率的优势

1. **简单直观**：只需 PE、ROE 两个核心参数，可心算。
2. **数学自洽**：PE、PB、ROE 三者关系清晰，可变换多种公式。
3. **同时考虑估值与盈利质量**：避免低 PE 陷阱和高 ROE 泡沫。
4. **有巴菲特案例支撑**：可口可乐、中国石油等案例较好对应。
5. **适用范围广**：通过第二、第三公式扩展至周期股和指数基金。
6. **可修正**：引入股利支付率、ROA 等适应不同企业类型。
7. **强调安全边际**：4～6 折买入原则与价值投资一致。

---

## 十、市赚率的局限与风险

1. **ROE 失真问题**：ROE 过高（>50%）或过低（<10%）时公式失效。
2. **修正系数是经验公式**：50% 分红标杆无严格理论推导，未来可能失效。
3. **周期股依赖商品价格**：若商品价格跌破前低，基于历史 ROE 的估值失去意义。
4. **可能阶段性失效**：如 2020 年“茅指数”牛市中，市赚率完全失效。
5. **隐形参数不稳定**：增长率、负债率、折现率等变化较大。
6. **卖出阈值主观性较强**：0.8PR、1PR 等阈值来自历史观察，并非精确公式。
7. **个人业绩可能存在幸存者偏差**：自称 10 年年化 20% 属个人回述，不一定普遍有效。

---

## 十一、综合理解

市赚率本质上是：

> **一个以 ROE 为锚，衡量“为盈利质量支付了多少估值溢价”的性价比指标。**

它特别适合：

- ROE 稳定的价值蓝筹
- 能用长期 ROE 平滑的周期股
- 以 PE、PB 估值的宽基或策略指数

但它并不是精确的定价模型，更适合作为：

- 初步筛选工具
- 买卖安全边际参考
- 与 DCF、股息率、产业周期结合使用的辅助指标

文章反复强调：**模糊的正确优于精确的错误**。

---

## 十二、总结表格

| 适用场景        |                         公式 |            关键参数 |            高估/卖出参考 |
| --------------- | ---------------------------: | ------------------: | -----------------------: |
| 稳定价值股      |          PR = PE / ROE / 100 |             PE、ROE |  A股 1PR，H股 0.8PR 左右 |
| 稳定价值股修正  | 修正PR = N × PE / ROE / 100 | PE、ROE、股利支付率 |             1PR 或 0.8PR |
| 周期股/困境反转 |        PR = PB / ROE² / 100 |    PB、多年平均 ROE | 1PR，保守 0.8PR 越涨越卖 |
| 指数基金        |         PR = PE² / PB / 100 |              PE、PB |     根据股息税和利率调整 |
| ROE 过高        |      衍生PR = PE / ROA / 150 |             PE、ROA |           类似价值股逻辑 |

---

**核心结论**：市赚率是一个有逻辑、有案例支撑、可扩展的估值工具，其核心价值在于将 PE 和 ROE 结合，避免单一指标的缺陷。但它有明确边界，对成长股、科技股、高杠杆股及极端市场风格下可能失效。理解公式背后的经济含义比机械套用阈值更重要。
