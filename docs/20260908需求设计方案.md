## 1. 背景与目标

现状（实测）：工作树 398.7 MB、`.git` 584.55 MiB（210 commits / 5 周）、三个主视图首屏加载 31–32 MB 未压缩 JSON、`analysis_dy.json` 30.7 MB 中 99.7% 前端不读、日常更新 5–8 分钟（其中 248 s 是纯 sleep）。

本期目标：

| 目标              | 量化指标                                                                |
| :---------------- | :---------------------------------------------------------------------- |
| G1 数据陈旧可见   | 任一标的滞后 >2 交易日必须出现在`status` 与失败清单                   |
| G2 主视图首屏瘦身 | 31.4 / 32.3 MB →**< 1 MB**                                       |
| G3 交付层压缩     | JSON 传输体积降至**10%–20%**                                     |
| G4 仓库增长       | 84 MB/月 →**< 20 MB/月**；噪声 commit 归零                       |
| G5 单一来源       | 前缀 /`pct_rank` / `IDX_DIV` / `UA` / ETF 元数据各 **1 份** |
| G6 CI 护栏        | 新增回归能在 CI 变红                                                    |

### R4 交付层压缩与缓存（P0）

| 项   | 内容                                                                                                                                                                                                                                          |
| :--- | :-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 现状 | `serve.py:52-56` 全量 `no-store`；无任何 gzip（实测 `Accept-Encoding: gzip` 仍返回原尺寸）                                                                                                                                              |
| 需求 | ①`.json/.js/.css` 启用 gzip（>1 KB 才压，按 `Accept-Encoding` 协商）；② `/cache`、`/web/data` 改 `Cache-Control: no-cache` + `ETag`（内容哈希），命中则 304；③ `web/js`、`web/css` 保持 `no-store`（开发期改代码即生效） |
| 验收 | `curl -sI -H "Accept-Encoding: gzip" /cache/analysis_dy.json` 出现 `Content-Encoding: gzip`；二次请求返回 304；数据重生成后 ETag 变化、刷新拿到新值                                                                                       |
| 风险 | 缓存策略写错会读旧数据 → 必须用 ETag 强校验（非`max-age`）                                                                                                                                                                                 |
