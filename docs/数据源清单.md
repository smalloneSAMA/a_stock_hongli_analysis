## 二、外部数据源明细

### 2.1 腾讯财经 · 批量行情快照（`qt.gtimg.cn`）

- **地址**：`https://qt.gtimg.cn/q=sh600036,sz000858,...`
- **实现**：`scripts/_common.py:76` `tencent_quotes()`，返回 `~` 分隔的原始字段数组
- **批量**：50 只/批（`TENCENT_BATCH`），批间 0.3s，GBK 解码
- **可获取数据（已实测使用的字段位）**：

| 字段位 | 含义 | 单位/口径 |
| ------ | ---- | --------- |
| `v[1]` | 证券名称 | — |
| `v[3]` | 现价 | 元 |
| `v[32]` | 涨跌幅 | % |
| `v[37]` | 成交额 | 万元（`/10000` → 亿元） |
| `v[39]` | PE(TTM) | 倍 |
| `v[44]` | ETF 总市值 ≈ 基金规模 | 亿元（语义见 `_fetch_etf_data.py:45` 的 TODO，尚未逐位验证） |
| `v[45]` | 总市值 | **已是亿元，勿再除 1e8** |
| `v[46]` | PB | 倍 |

- **消费方与落地**：
  - `_update_summary.fetch_quotes` → `cache/_成分股汇总.json`（`t_price/t_pe/t_pb/t_mcap/change_pct`）
  - `_fetch_watchlist.refresh_indicators_main` → `cache/_自选股指标.json` + 写回 `excel/自选股清单.xlsx`
  - `update.update_etfs` → `cache/_ETF规模.json`（`scale_yi`）
  - `_gen_components.tencent_names` → 成分股名称补齐
- **覆盖标的**：全部个股（推荐 20 + 其他成份股 + 自选股）+ 12 只 ETF。指数行情不走此接口（指数代码前缀与个股不同，走 2.2/2.3/2.4）

### 2.2 腾讯财经 · K 线（`web.ifzq.gtimg.cn`）

- **地址**：`https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={code},day,{start},{end},800,{fq}`
- **可获取数据**：`[date, open, close, high, low, volume, amount?]`
  - `volume` 单位：手；`amount` 字段不保证存在（可能是分红除权 dict）
  - 复权：指数/ETF 传 `qfq`（前复权，`_fetch_history.py:110`）；股票传空 = **不复权**（`_fetch_stock_data.py:448`，因前复权早期价格会为负）
- **落地**：`cache/指数_{code}.json`、`cache/ETF_{code}.json`、`cache/股票_{code}.json`
- **注意**：接口 `start` 参数对股票实测无效（总返回最近 800 条），故股票增量=拉最近 800 条做字段级合并；指数/ETF 用 `end` 向前翻页实现全量
- **成交额缺口**：腾讯日 K 无可靠成交额 → 股票/ETF 按 `成交量(手)×100×(最高+最低+收盘)/3` 估算（`_fetch_history.fill_etf_amount`，实测误差 <1%）

### 2.3 中证指数官网（`csindex.com.cn` / `oss-ch.csindex.com.cn`）

三处用途，共用 5 只指数（H30269、930955、932315、931468、H30270）+ 全部 9 只中证指数成分：

1. **历史行情** `csindex-home/perf/index-perf?indexCode=&startDate=&endDate=`
   - 字段：`tradeDate`、`open`、`high`、`low`、`close`、`change`、`changePct`、`tradingVol`（股）、`tradingValue`（亿元）
   - 按年分段拉取 + 1.5~2.5s 间隔防限流
2. **官方样本/权重文件** `.../autofile/cons/{code}cons.xls` 与 `.../autofile/closeweight/{code}closeweight.xls`
   - cons 取第 0/4/5/7 列 = 样本截止日、代码、名称、交易所
   - closeweight 取第 0/4/5/9 列 = 权重截止日、代码、名称、权重%
3. **前十大权重** `csindex-home/index/weight/top10new/{code}` → `securityCode` + `weight`

**覆盖 9 只指数**：000922 中证红利、000015 上证红利、000821 沪深300红利、000825 中证央企红利、H30269 中证红利低波动、930955 红利低波动100、932315 中证全指红利质量、931468 中证红利质量、H30270 中证红利价值

**落地**：`cache/指数_{code}.json`；成分 → 重写 `红利指数与ETF成分股.md` → `cache/_成分股汇总.json` / `_成分股汇总表.json`

### 2.4 国证指数官网（`cnindex.com.cn`）

- **成分**：`https://www.cnindex.com.cn/sample-detail/detail?indexcode=980092&dateStr=&pageNum=1&rows=100`（需 Referer）
  - 字段：`seccode`（代码）、`secname`（名称）、`trade`（**国证行业分类，非申万**）、`weight`（权重，仅前十大有值，其余 `--`）、`dateStr`（样本日期）、`total`
  - 落地：`cache/成分_980092.json`（含 `top10`、`industry_dist`）+ `excel/国证指数成分.xlsx`
- **行情**：`https://hq.cnindex.com.cn/market/market/getIndexDailyDataWithDataFormat?indexCode=980092&startDate=&endDate=&frequency=day`
  - 返回列式 `data.item`（列名）+ `data.data`（行），使用 `timestamp/open/high/low/close/volume/amount`
  - 单位：`volume`=万手、`amount`=亿元

### 2.5 东方财富（`datacenter-web` / `push2*` / `emweb`）

全项目唯一限流入口：`_common.em_get`（全局 1s/请求 + 0.1~0.4s 抖动，线程安全）。

| 用途 | reportName / 端点 | 关键字段 | 落地 |
| ---- | ----------------- | -------- | ---- |
| 分红历史 | `RPT_SHAREBONUS_DET` | `EX_DIVIDEND_DATE`、`PRETAX_BONUS_RMB`（每 10 股税前派息） | `cache/分红_{code}.json` → `[{ex_date, bonus10}]` |
| 季度财报 | `RPT_F10_FINANCE_MAINFINADATA` | `REPORT_DATE`、`NOTICE_DATE`、`EPSJB`、`PARENTNETPROFIT`、`TOTAL_SHARE`、`BPS`、`ROEJQ`、`ZZCJLL` | `cache/财报_{code}.json` → `[{report_date, notice_date, eps, np, share, bps, roe, roa}]` |
| 股本变动 | `RPT_F10_EH_EQUITY`（回退 `PC_HSF10/CapitalStockStructure/PageAjax` 的 `lngbbd`） | `END_DATE`、`TOTAL_SHARES` | `cache/股本_{code}.json` → `[{date, total_share}]` |
| 行情+行业 | `push2delay/api/qt/stock/get?fields=f57,f58,f43,f127` | `f43` 现价、`f57` 代码、`f58` 名称、`f127` 申万行业 | `_成分股汇总.json`、`_自选股清单.json` |
| 指数成分 | `RPT_INDEX_COMPONENT`（`INDEX_CODE=000151`） | `SECURITY_CODE` | 仅 000151（官网样本文件未公开，东财口径 30 只） |

**由上述源派生、不再触网计算的指标**（口径在 `_fetch_stock_data.py`）：

| 指标 | 计算式 | 依赖源 |
| ---- | ------ | ------ |
| 股息率 `dy` | 近 365 自然日除权派息合计 ÷ 当日收盘 × 100 | 分红 + 腾讯 K 线 |
| PE(TTM) | 收盘 × 当日总股本 ÷ TTM 归母净利 | K 线 + 财报 + 股本 |
| PE(动) | 总市值 ÷ (最新累计归母净利 × 季度年化系数 4/2/4/3/1) | 同上 |
| PB | 收盘 ÷ 最新已公告 BPS | K 线 + 财报 |
| PEG | PE-TTM ÷ TTM 净利同比增速（增速 ≤0 记 None） | 财报 |
| ROE / ROA | 最新已公告报告期 `ROEJQ` / `ZZCJLL` | 财报 |
| 30/60/90 日涨跌 | 交易日口径（非自然日） | K 线 |

### 2.6 天天基金（`fundf10.eastmoney.com`）

- **地址**：`https://fundf10.eastmoney.com/FundArchivesDatas.aspx?type=jjcc&code=159201&topline=10&year=2026&month=9`（需 `Referer: https://fundf10.eastmoney.com/`）

## 五、限流与防封约定（改抓取前必读）

| 源 | 限流 | 依据 |
| -- | ---- | ---- |
| 腾讯批量行情 | 50 只/批，批间 0.3s | `_common.TENCENT_BATCH` |
| 腾讯 K 线 | 全局限速 0.8s/请求，3 并发；实测更快会触发 501 临时封禁 | `RateGate(interval=0.8)`，困难总结 155 |
| 东财全接口 | 全局 1s/请求 + 0.1~0.4s 抖动，加锁串行 | `_common.em_get` |
| 中证官网 | 按年分段 + 1.5~2.5s 间隔 | `_fetch_history.fetch_csindex_perf` |
| 国证官网 | 0.6s/请求 | `_fetch_history.fetch_cnindex_kline` |
| 新浪净值 | 0.6s/页 | `_fetch_history.fetch_sina_nav` |
| 熔断 | 连续 5 次失败暂停 60s；东财连续 8 次失败中止该补齐环节 | `parallel_map(melt_limit=5)`、`FAIL_LIMIT=8` |

失败清单：`cache/_pool_failed.json`、`cache/_watchlist_failed.json`；陈旧检测：`cache/_stale.json`（基准=全池最新行情日，落后 >5 自然日告警）。

## 六、已知缺口（无数据源 / 靠估算）

1. **北交所个股**：无可用数据源，`is_bj()` 标的直接剔除，不入池（失败清单里 92/83/87/88 开头属预期失败）。
2. **成交额**：腾讯日 K 不提供可靠成交额，股票与 ETF 均为「量×100×均价」估算；指数成交额来自中证/国证官网原始字段。
3. **ETF 精确持仓**：除 980092 相关的 8 只现金流 ETF 有季报前十大外，其余 11 只 ETF 持仓直接以「跟踪指数成分股」列示（合同约定，存在跟踪误差）。
4. **980092 权重**：国证官网仅公开前十大权重，其余 90 只为空，加权股息率为前十大估算值。
5. **000151 成分**：中证官网样本文件未公开，改用东财指数成分表（30 只，与官方 50 只口径不一致）。
6. **腾讯 `v[44]`（ETF 规模）**：字段位语义未经逐位验证，沿用原实现（见 `_fetch_etf_data.py:45` TODO）。
7. **`scripts/_archive/`** 下的 6 个脚本（含 `_candidate_dy.py`、`_recommend_data.py` 等）已无引用，其产物 `_候选股息率.json`、`_全市场清单.json`、`_调研_红利ETF全市场.json` 属历史遗存，**不在当前链路中**。
